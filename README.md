# NŪRAN | نوران

Luxury Saudi-first supplements storefront concept built as a polished portfolio demo.

## Highlights
- Arabic RTL responsive storefront
- Product catalog with filtering and sorting
- Product detail modal
- Cart with quantity controls and local persistence
- Wishlist persistence
- Search overlay
- Bundle add-to-cart flow
- Saudi Riyal pricing
- Responsive mobile navigation
- Demo-safe medical/content disclaimers

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deployment
Optimized for Vercel static deployment.

> All products, prices, reviews and commercial details are fictional/demo content.
